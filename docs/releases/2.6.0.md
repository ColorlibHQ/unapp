# Unapp 2.6.0 release

Released 28 October 2026, with Unapp Library 1.1.0.

## Included

Nineteen free niche starters, 232 inserter patterns and original bundled imagery. Setup now includes a searchable starter finder, one-page/full-site choices, real service cards, optional sections, main-action selection and a private personalized preview. The resumable Finish your website workspace guides native page/image editing and editor return shortcuts. Header/footer presets and compatible section swaps support preview and Undo. Additional launch recommendations cover icons, links, search visibility and image descriptions without blocking progress.

Unapp Library adds review-before-apply AI proposals with ownership, expiry and stale-content protection. Its optional external AI providers may charge for API use; the theme, starter designs and native setup require no paid service.

User instructions: [Getting started](../getting-started.md). Technical details: [Updates and privacy](../updates.md), [complete changelog](../../CHANGELOG.md).

## Release procedure

1. Regenerate patterns/styles and confirm no unexpected generated changes; refresh the translation template.
2. Run `.dev/check.py`, WordPress integration checks and the browser suites in an isolated installation. Run Theme Check on the packaged ZIP.
3. Build both ZIPs with `.dev/build-zip.sh`; publish immutable GitHub assets and versioned R2 downloads.
4. Refresh all demos and catalogue screenshots from the canonical `.dev/export-catalog.php` manifest; publish Colorlib's landing page, documentation and hub entries. Register every demo in update-host monitoring.
5. Publish theme/plugin versions using the existing update service's `release.mjs`, then verify feeds, downloads and a native WordPress upgrade from the previous release.

## Automatic updates

WordPress discovers this release through its normal update checks. Sites with native theme/plugin auto-updates enabled install it on their usual schedule; other sites receive the standard update notice. The release does not override site owners' preferences or replace their content. A theme update does not automatically apply a different starter. Users can choose **Dashboard → Updates → Check again** to refresh immediately.
