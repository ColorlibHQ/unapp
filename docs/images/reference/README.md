# Illustrated reference screenshots

Twenty-one screenshots captured with Playwright from the released Unapp 2.6.0 interface on WordPress 7.1.3. Admin screens use the disposable Oak & Stone tutorial installation, including WooCommerce sample products. Storefront screenshots are read-only captures of the public Unapp Shop demo. No customer or public demo content was changed for this documentation.

Lossless WebP files preserve readable controls. The public Colorlib documentation project uses these images on Setup reference, Colours and type, Patterns, Starter sites, WooCommerce, Updates, Extending and FAQ. Each figure has a task caption, intrinsic dimensions, lazy loading and a native-dialog full-size view with keyboard support.

The documentation source and `tools/check-unapp-reference.cjs` live in the local `colorlib-docs` project. After refreshing images, verify captions against the real screen, capture dimensions, internal topic links, all image responses, actual-size viewing and 1440/390/320 px layouts. Never commit login cookies or API keys.
